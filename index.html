► Rori

[Closed beta]

AI review of medical records, built with a physician co-founder and now in closed beta with a medical group.

Doctors doing workers' compensation reviews get thousands of scanned pages per patient. Rori splits them into individual records, dates and categorizes each one, and writes the summaries. Then the same agent behind its chat builds the patient's medical chart: an overview, demographics, medications, diagnoses, allergies and more. A 667-page test case comes back as 141 summarized records, with no failed calls.

  • Async pipeline on Java 25 virtual threads: Textract OCR, then LLM indexing and summaries, each checked by a second QA pass.
  • One LLM layer over Gemini, Claude and NVIDIA NIM, with retries, backoff and fallback to a second model when rate-limited.
  • Cut pipeline cost by 62%, to under $0.01 a page, with a model change and explicit context caching.
  • "Ask Rori" is a streaming chat agent that answers from the patient's records and cites them, and every citation is checked against records the user owns.
  • AWS with Terraform (ECS, Lambda, Aurora DSQL, Cognito, S3, KMS), GitHub Actions over OIDC, 700+ tests.
Stack
Java, Spring Boot, Spring AI, React, TypeScript, Python, AWS, Vertex AI
